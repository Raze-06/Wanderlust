🌍 StayVista – Travel Listing Platform

📌 Overview
StayVista is a full-stack web application that allows users to explore and share unique travel stays across different locations. The platform supports secure authentication, listing management, reviews, and location-based features to provide an interactive user experience.

 🚀 Features

- 🔐 **Authentication & Session Management**  
  Secure user signup/login/logout using Passport.js with session-based authentication and flash messaging.

- 🏡 **Listings Management (CRUD)**  
  Create, view, update, and delete listings with owner-based authorization and server-side validation using Joi.

- 🖼️ **Image Uploads & Media Handling**  
  Integrated Cloudinary for efficient image storage with automatic cleanup on updates and deletions.

- 📍 **Location & Map Integration**  
  Implemented Geoapify for geocoding and MapLibre to display interactive maps for each listing.

- ⭐ **Review & Rating System**  
  Users can add and delete reviews with ratings, with access control to ensure only authors can modify their content.

- 🔍 **Search & Filtering**  
  Implemented search and filtering functionality to help users quickly find listings based on their preferences.
